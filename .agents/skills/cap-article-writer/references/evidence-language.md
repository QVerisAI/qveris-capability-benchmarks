# Evidence language

Use evidence states precisely:

- `verified`: every frozen round for the representative case met the CAP contract.
- `provider_negative`: every frozen round produced an explicit Provider-level negative outcome. It does not prove permanent lack of support.
- `not_applicable`: the frozen Access Path contract excluded the cell. It is not a failed test.
- `evidence_insufficient`: the Release cannot support either a positive or Provider-negative conclusion.

Keep these categories separate:

- Live measurements versus official Provider statements versus editorial recommendations.
- QVeris Inspect list price versus direct Provider plans versus account-billed consumption.
- Provider identity versus Access Path identity.
- Representative-case verification versus universal market or instrument support.

Phrase recommendations as conditional decisions: “Choose the selected path when this released dimension is the priority.” Never generalize to the Provider's full native API surface.
