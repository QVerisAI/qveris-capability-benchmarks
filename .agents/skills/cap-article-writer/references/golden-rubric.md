# Golden article rubric

The rendered article passes only when a developer can answer all of these questions without opening internal artifacts:

- What was tested, when, through which Access Paths, and with what evidence boundary?
- Which path fits each important use case, and what trade-off qualifies that recommendation?
- What do the four market evidence states mean?
- How should both charts be read, and what should not be inferred from them?
- What did each Provider × Access Path actually return in a representative successful sample?
- Which Agent-interface risks were observed, and which remain unmeasured?
- How can a reader reproduce the publication offline without Provider keys?
- How can a reader create a new immutable live Release with their own key?
- How can Providers contribute or request a correction?
- What are the CAP, sample, latency, pricing, and market limitations?

Reject drafts that only contain a comparison table, generic Provider summaries, or a marketing CTA. The editorial layer must add interpretation; deterministic blocks supply facts.
