③ 分阶段说明

01 选题：CAP 怎么进

唯一来源是 Harbor catalog 的 CAP 契约接口。两层过滤：

  • 可评测性：coverage=full 且 provider_count ≥ 3（当前 57 个）
  • 选型价值：报价 → 参考 → 新闻 → 基本面，按 provider_count 降序

选题时查 QVeris 存量 guide，撞意图的跳过（例如财经新闻已有对比文，改做公司行动、分红等空档）。

02 出题：题目是契约的实例

契约字段对应题目
standard_query.required题目输入（如 symbol、日期窗口）
field_spec.required期望观察字段（如 amount、ex_date、currency）
工具注册表 market 标签（per-tool）市场覆盖题（Harbor 的 scope.market_hint 已不再使用）
契约负向约束boundary_negative：无效代码 / 缺必填组合 / 不支持枚举

题目角色直接映射维度族：core_positive → 准确度/完整度；boundary_negative → 错误恢复；coverage → 市场覆盖；agent contract → AI 落参与解读。

03 选供应商：谁进短名单

  1. Harbor coverage 快照只用于列候选，不作结论依据
  2. QVeris provider 页存在且验证 HTTP 200
  3. 有执行授权（Direct Test 要真跑；无凭据 → N/A，不算低分）
  4. 同一法律实体只占一行（Massive/Polygon 合并、恒生 REST/MCP 合并）
  5. 对比文至少 3 家合格才发；不够只写单供应商测评

04 定维度：通用算子 × 契约实例化

算子测什么由谁实例化
required_field_presence完整度field_spec.required
field_type_validity准确度field_spec 类型/enum
row_key_completeness数据形态output_cardinality + row_key
timestamp_freshness时效时间语义字段
market_routing市场覆盖工具注册表 market 标签 + 官方声明（复用 Harbor SV 作交叉核对）
language_mapping语言覆盖语言字段（有意义才测）
latency / reliability / cost网关表现执行 trace + billing
agent_param_fillAI 入参落参standard_query.required + 题目
agent_response_interpretationAI 出参解读题目观察字段 + 响应 schema

05 Direct Test：自己判合格

  • 固定用例：正向（真实标的检索）+ 负向（无效代码控制）
  • 每个适用单元 2 轮，经 QVeris 真实执行
  • 正向判定：契约必填字段全部返回且非空 → 过
  • 负向判定：返回空态或明确报错、不编造事件行 → 过
  • 执行 401 / 无授权 → N/A
  • 从执行响应采集自己的延迟与费用（文章数字来源）

06 AI 友好度：入参 + 出参

同一个自然语言任务交给 DeepSeek Flash，每工具 2 轮：

  • 入参落参：只调 canonical 工具、必填齐全、类型合法、不幻觉多余参数、语义正确
  • 出参解读：给冻结的真实响应，AI 读出金额/日期/单位是否正确、不添油加醋、负向不编造

两步都过才算"AI 友好"；任何一步失败意味着 Agent 自动调用需要人工兜底。

07 判定与证据

状态含义示例
合格所有适用单元通过，2 轮稳定分红 6 家全部 4/4
未完全达标任一单元失败公司行动 Alpha Vantage（Harbor 快照口径）
未测无 canonical 工具或未授权，不评分分红 FMP / Yahoo
N/A契约不适用无执行授权

原始证据落 evidence/private/（gitignored）：供应商、用例、轮次、检查项、延迟、费用、时间戳。

08 写文章

固定结构（参照流量文）：快速结论 → 直接回答 → 固定对比表+图 → 测试方法与证据分级 → 达标标准 → AI 友好度（带走查例子+图）→ 市场覆盖（矩阵+图）→ 场景推荐 → 深度解析 → 局限 → FAQ → 更正/复测 CTA。

证据分级允许的说法
实测带日期、固定输入、连接器口径："2026-08-09 经 QVeris 网关实测"
官方来源供应商文档声明，带直接链接
编辑解读时间限定的买方建议："本次测试最佳适配"

09 画图

图表从证据文件计算生成，不是手画：render_cap_guide_charts.py 读取 evidence/private/ 最新一批，输出三张图并记录输入 digest 到 charts-manifest.json：

  • 延迟 × 单次费用散点
  • AI 入参通过率柱状（含出参样本标注）
  • 市场覆盖热力图

换数据重跑即可复现，图片与证据绑定。

10 发布与复测

  • 发布前：全部链接实测 200（官网 / provider 页 / 官方文档）、manifest 完整、正文无内部信息
  • 复测：每次出新版跑同一套固定用例（Direct Test + 两个 AI 探针，2 轮），目标 2–4 小时
  • 与 Harbor 不一致：以自己实测为准 + 去 Harbor 提 issue（例如公司行动 Alpha Vantage，issue #1368），不阻塞发布

⑤ 红线

  • Harbor 评估只作候选与异常参考，发布的合格结论必须来自本平台 Direct Test + AI 探针
  • 正文不暴露 CAP ID、不暴露 grade、不合成总分、不写"永久最优"
  • 无执行授权 = N/A，不是低分；缺证据 = 未测，不是结论
  • 图表必须从绑定证据生成，禁止手填数值
  • 发现快照异常 → 提 issue 跟进，但不阻塞发布
