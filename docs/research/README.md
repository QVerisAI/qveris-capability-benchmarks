# External Research Index

This directory records external research that informs benchmark design. It is
not release evidence, a provider claim, or a source of executable benchmark
questions.

## Boundaries

- Store bibliographic metadata, stable public links, and concise design notes.
- Do not commit paper PDFs unless their licence explicitly permits repository
  redistribution and the addition is reviewed for size and provenance.
- Keep a paper's influence explicit: it may motivate a future CAP or method,
  but it never changes a released outcome without CAP-defined measurement and
  release evidence.
- Record task text from an external benchmark only through the question-bank
  provenance policy; this index must not duplicate external datasets.

## Collections

- [Agent capability evaluation](agent-capability-evaluation.md): Agent,
  tool-use, MCP, reliability, and trust-layer research relevant to this
  platform.

## Curation workflow

1. Add a paper with an immutable identifier (prefer an arXiv ID or DOI), a
   public landing page, and a date checked.
2. State the narrow design implication and the non-implication for this
   repository.
3. Mark the item as `read`, `candidate`, or `superseded`; do not treat the
   index as an endorsement or a ranking.
